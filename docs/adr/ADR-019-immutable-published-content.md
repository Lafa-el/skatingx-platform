# ADR-019: 不可变已发布内容 + 指针式发布

## 状态

提议（2026-11-12）

## 背景

已发布内容须可信、可回溯；修正不能改写已发布版本。

## 决定

- 已发布版本不可变；修正产生新版本（`contentVersion` 递增），不改旧版本。
- 发布用指针（`publishedVersion`）加特性开关；回滚只动指针与开关，不删版本与用户历史。
- 版本内容带 `checksum`；发布须审核人与最后编辑人不同（可行时）；`status` 与 `reviewStatus` 分离。
- 未发布（`draft` / `in_review`）内容普通用户不可读（见 ADR-020）。

## 回退

回退本提交。指针与开关的回滚由 P5 的发布流程执行。
