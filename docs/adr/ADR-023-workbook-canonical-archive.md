# ADR-023: 源工作簿是规范性存档数据；版本化 JSON 是部署产物

## 状态

提议（2026-11-12）

## 背景

工作簿是 257 个对象的权威来源；JSON 是导入产物。

## 决定

- 源工作簿字节不变（SHA-256 `15e36d07501eaa514fc74a069060a56e1b387df8825f3369f1966112c93b180b`，P0-1 已验）；工作簿是规范性存档数据。
- 版本化 JSON（staging 清单）是部署产物，可由解析器重建（P0-1 已验证可重复生成）；JSON 不作为权威来源。
- legacy id（`stb_*` 等）进 `legacyAttributes`，不作主键；BL-L031 与 BL-I017 无 legacy 生产映射，照常导入。
- 工作簿版本 V1.3.2 与规范 V2.0 的关系：工作簿是源数据，规范是新技术合同。

## 回退

回退本提交。解析器与清单不受影响（P0-1 已合入）。
