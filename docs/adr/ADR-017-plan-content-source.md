# ADR-017: 计划内容源统一

## 状态

已接受（2026-11-12）

## 背景

计划页原来用手写 Junior D 模板（21 张日卡 + 76 条任务切分）。学院已有按年龄段分的 routine。两份内容重复，改一处漏一处。

## 决定

- 计划生成与页面改读学院 routine，按真实年龄取阶段（D1）。
- 侧重是本周的形状（3×7 形状表）加上按链接模块分类排序，endurance 上限 4（D2）。
- 周三和周日是恢复日，只展示不生成。没有 routine 的日显示休息（D4）。
- 没有出生日期时显示提示，不生成任务。
- 各阶段写 7 行每日文案。11–13 岁先行，4–7、8–10、14–16 岁随后补齐。没有自有文案的段用通用句（D3）。17–18 岁目前用通用句。
- 旧模板退役：`PLAN_DAY_ENTRIES`、`PLAN_DAY_COPY`、`planCandidatesFor`、`planDayIdFor`、`planDays` 已删除。`PLAN_DAYS` 与 `planDayById` 保留，供积分历史解析已存的 `plan-checkin` refId。
- 计划生成免费。学院导入仍走 PRO（D7）。

## 回退

回退本提交后，这三段的每日文案回到通用句，ADR 一并撤下。要回到旧 Junior D 模板，需要连 Phase 3 一并回退。已经生成的任务只存文本，不受影响。
