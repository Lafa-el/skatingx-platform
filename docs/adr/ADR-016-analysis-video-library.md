# ADR-016: 分析视频库与可选 videoId

## 状态

已接受（2026-11-10）

## 背景

分析需要一份用户自己的视频记录，用来从库里打开动作分析，并把那条记录的 id 写回分析文档。比赛日视频（ADR-010）是另一条路径，不能改。

## 决定

- 视频库存 `users/{uid}/videos/{id}`。这是用户级集合，不按运动员拆。现有 `users/{uid}` 通用 owner 规则已经覆盖它，本步不给这个集合加新规则。
- 动作分析记录可以带可选 `videoId`（1–64 字符，允许 `addDoc` 的大小写）。没有这个字段的旧记录仍然合法。配速记录不带 `videoId`。
- 「已分析 / 未分析」不落库，从当前运动员已保存的分析记录推导。

## 回退

回退本提交。`videoId` 是可选字段，旧记录不受影响。如果这条规则已经发布，回退时要重新发布上一版规则；未发布则分析保存时带 `videoId` 会被当前线上规则拒绝，不带 `videoId` 的保存仍可用。
