# ADR-007: 家长 PIN 守门面（DR-011 的最小实现）

| 字段 | 值 |
|---|---|
| 状态 | 提议。本切片按 2026-10-22 的实现任务落地。 |
| 日期 | 2026-10-22 |
| 分支 | `feat/parent-pin-gate` |
| 依据 | DR-011（已批选项 A：不明文、Firestore 存哈希、可跨设备）。本切片与选项 A 的算法一句冲突，见下。 |
| 不做 | 不改 Security Rules。不迁旧站明文 PIN。不把 PIN 做成账户安全边界。不加失败锁定。不接支付，不写 `isPro`。 |

## 冲突

DR-011 备注写「只存 bcrypt/argon2」。浏览器没有这两套算法的 WebCrypto 实现，引入它们要加依赖。本任务指定：哈希 = WebCrypto SHA-256(salt + PIN)，salt 随机生成，字段是 `settings/main.parentPinHash` 与 `parentPinSalt`。明文不落库、不进日志、不进测试快照。

这是误触门，口径与 PRO 门相同：防止随手点到改密码邮件、删除运动员、订阅开通或变更。它不防止拿到设备的人、也不防止能读 Firestore 的人。不把文案写成安全锁。

## 选择

- 已设置 = 两个字段都是非空字符串。未设置时三个动作直接执行，账号分组里提示建议设置。
- 验证通过后把当前 uid 写入 `sessionStorage`。退出登录成功后清掉。换一个 uid 对不上，解锁也不再生效。
- 修改 PIN 先核对旧 PIN，再换一把新 salt。

## 影响与回退

只多两个可选字段，属主本来就能写 `settings/main`。回退：停写这两个字段，界面不再读它们；已写入的哈希可以留在文档里，应用忽略即可。没有规则或索引变更。
